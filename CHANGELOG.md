# Changelog

All notable changes to Searvo will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-03-15

### Added
- Initial release of Searvo
- AI-powered search with RAG capabilities
- Multi-provider LLM support (OpenAI, Google, Anthropic, Ollama, OpenRouter)
- Voice input and output features
- Web scraping for full content extraction
- @mentions for site-specific search
- Multi-platform support (Android, iOS, Web, Linux, macOS, Windows)
- Dark/Light theme support
- Settings management
- Docker configuration for SearXNG

### Features
- Conversational search with context awareness
- Real-time response streaming
- Voice-enabled hands-free operation
- Export to PDF, Markdown, JSON
- Responsive design for all screen sizes

### Technical
- Flutter 3.8+ framework
- Provider state management
- GoRouter navigation
- LangChain LLM integration
- SharedPreferences storage
- Speech-to-text and text-to-speech
